# Link Tracker

Приложение для отслеживания изменений по ссылкам, добавленным пользователем через Telegram-бот.
Сервис автоматически анализирует содержимое ресурсов (GitHub, StackOverflow и обычные HTML-страницы), определяет обновления и уведомляет пользователя о них.

Проект написан на `Java 23` с использованием `Spring Boot 3`.

Проект состоит из 2-х приложений:
* Bot --- Telegram-бот, обрабатывающий команды пользователя
* Scrapper --- сервис, выполняющий анализ и обновление ссылок

Данные хранятся в `PostgreSQL`, миграции выполняются через `Liquibase`.
Для обработки внешних запросов используются `WebClient` и `Jsoup`.
